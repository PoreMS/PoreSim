# Pore System Simulation Generator

This Python package generates simulation folders and GROMACS run scripts for
pore systems built with [PoreMS](https://porems.github.io/PoreMS/).
To see the code or report a bug, please visit the
[GitHub repository](https://github.com/PoreMS/PoreSim).

## Tutorials

- [Simulation Setup](simulation.md) — single-phase pore simulation
- [Complex Pore Simulation](simulation_complex.md) — multi-molecule setups
- [Two-Phase Simulation](simulation_2ph.md) — two-phase liquid systems

The [API reference](api.rst) documents every module in full.
